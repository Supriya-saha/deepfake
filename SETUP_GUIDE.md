# MMFN - Multimodal Fake News Detection

This project implements a Multimodal Fake News detection system using BERT, Swin Transformer, and CLIP models to analyze both text and images from social media posts.

## 🚀 Quick Start

### Prerequisites

- Python 3.8 or higher
- CUDA-capable GPU (recommended for training)
- Git (for cloning external dependencies)

### Automated Setup

We provide setup scripts for easy installation:

#### Windows (PowerShell)

```powershell
# Run the setup script
.\setup_dependencies.ps1
```

#### Linux/Mac (Bash)

```bash
# Make the script executable
chmod +x setup_dependencies.sh

# Run the setup script
./setup_dependencies.sh
```

The setup script will:
1. Create a Python virtual environment
2. Install all required packages
3. Download external model files (CLIP vocabulary)
4. Verify dataset structure
5. Run preprocessing if needed

### Manual Setup

If you prefer manual setup:

1. **Create virtual environment**
   ```bash
   # Windows
   python -m venv venv
   .\venv\Scripts\Activate.ps1
   
   # Linux/Mac
   python3 -m venv venv
   source venv/bin/activate
   ```

2. **Install dependencies**
   ```bash
   pip install --upgrade pip
   pip install -r requirements.txt
   ```

3. **Download CLIP vocabulary file**
   ```bash
   curl -L -o bpe_simple_vocab_16e6.txt.gz https://github.com/openai/CLIP/raw/main/clip/bpe_simple_vocab_16e6.txt.gz
   ```

4. **Preprocess dataset** (if not already done)
   ```bash
   cd data
   python twitter_preprocess.py
   cd ..
   ```

## 📦 Dependencies

### Core Libraries
- **PyTorch** - Deep learning framework
- **Transformers** (Hugging Face) - BERT and Swin Transformer models
- **CLIP** (OpenAI) - Vision-language model
- **scikit-learn** - Machine learning metrics
- **pandas** - Data processing
- **opencv-python** - Image processing
- **langdetect** - Language detection for preprocessing

### Pre-trained Models (Downloaded Automatically)
- `bert-base-chinese` (~400MB) - Text encoder
- `microsoft/swin-base-patch4-window7-224` (~350MB) - Image encoder
- `OpenAI CLIP ViT-B/32` (~350MB) - Multimodal embeddings

Models are cached in `~/.cache/huggingface/` (Linux/Mac) or `C:\Users\<username>\.cache\huggingface\` (Windows).

## 📁 Dataset Structure

The project expects the following directory structure:

```
MMFN_yyt-master/
├── dataset/
│   └── twitter/
│       ├── train_posts.txt          # Raw training data
│       ├── test_posts.txt           # Raw test data
│       ├── images_train/            # Training images
│       ├── images_test/             # Test images
│       ├── train_tweets_preprocess.csv  # Generated by preprocessing
│       └── test_tweets_preprocess.csv   # Generated by preprocessing
├── data/
│   ├── twitter_preprocess.py        # Preprocessing script
│   ├── weibo_preprocess.py
│   └── gossip_preprocess.py
├── trainMMFN.py                     # Main training script
├── MMFN.py                          # Model definition
├── twitter_dataset.py               # Dataset loader
├── clip.py                          # CLIP utilities
├── model.py                         # Additional model components
└── simple_tokenizer.py              # CLIP tokenizer
```

### Dataset Format

The raw data files should be tab-separated with the following columns:
```
post_id    post_text    user_id    image_id    username    timestamp    label
```

- `label`: "fake" or "real"
- `image_id`: comma-separated image identifiers

## 🎯 Usage

### Training

After setup, run the training script:

```bash
python trainMMFN.py
```

The script will:
1. Load the preprocessed Twitter dataset
2. Initialize the multimodal model
3. Train for up to 50 epochs with early stopping
4. Save the best model as `best_model.pth`
5. Display evaluation metrics (accuracy, precision, recall, F1-score)

### Preprocessing Only

To regenerate preprocessed files:

```bash
cd data
python twitter_preprocess.py
```

This script:
- Filters for English language posts
- Checks for image existence
- Filters out videos
- Converts labels to binary (0=fake, 1=real)
- Generates `train_tweets_preprocess.csv` and `test_tweets_preprocess.csv`

### Using Different Datasets

The project supports multiple datasets:

**Twitter** (default):
```python
from twitter_dataset import twitter_dataset
train_set = twitter_dataset(is_train=True)
```

**Weibo**:
```python
from myweibo_dataset import weibo_dataset
train_set = weibo_dataset(is_train=True)
```

**GossipCop**:
```python
from gossipcop_dataset import gossipcop_dataset
train_set = gossipcop_dataset(is_train=True)
```

## 🛠️ Configuration

### GPU Settings

By default, the code uses GPU 0 if available:

```python
os.environ["CUDA_VISIBLE_DEVICES"] = "0"
device = "cuda" if torch.cuda.is_available() else "cpu"
```

To use a different GPU or CPU only, modify `trainMMFN.py`.

### Hyperparameters

Key hyperparameters in `trainMMFN.py`:

```python
batch_size = 32          # Batch size for training
patience = 5             # Early stopping patience
num_epochs = 50          # Maximum training epochs
learning_rate = 0.0001   # Learning rate for BERT/Swin
lr_other = 0.001         # Learning rate for other layers
```

## 📊 Model Architecture

The MMFN model combines:
1. **BERT** - Processes textual content
2. **Swin Transformer** - Extracts image features
3. **CLIP** - Generates multimodal embeddings
4. **Cross-modal Transformer** - Fuses text and image features
5. **Classification Head** - Binary classification (fake/real)

## 🐛 Troubleshooting

### Common Issues

**1. Import Error: No module named 'cv2'**
```bash
pip install opencv-python
```

**2. FileNotFoundError: bpe_simple_vocab_16e6.txt.gz**
```bash
curl -L -o bpe_simple_vocab_16e6.txt.gz https://github.com/openai/CLIP/raw/main/clip/bpe_simple_vocab_16e6.txt.gz
```

**3. ImportError: cannot import name 'packaging'**
```bash
pip install packaging
```

**4. CUDA out of memory**
- Reduce `batch_size` in `trainMMFN.py`
- Use CPU by setting `device = "cpu"`

**5. Preprocessing fails with KeyError**
- Ensure your dataset has the correct column names
- Check `data/twitter_preprocess.py` for expected format

- Validation metrics
- Best model checkpoint saved automatically
